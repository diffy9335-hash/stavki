# 🎲 Betting Bot (Telegram, aiogram 3 + SQLite)

Бот с виртуальными монетами: ставки на матчи, экспрессы, 7 игр, промокоды,
бонусы со серией, достижения, рефералы, топы с призами, админ-панель.

## Установка

1. Python 3.10+
2. `pip install -r requirements.txt`
3. Создайте бота через @BotFather
4. **Токен** — либо в `config.py`, либо безопаснее через переменную окружения:
   - Windows PowerShell: `$env:BOT_TOKEN="ваш_токен"`
   - Linux: `export BOT_TOKEN=ваш_токен`
5. Узнайте свой Telegram ID через @userinfobot, впишите в `ADMIN_IDS`
6. Запуск: `python main.py`

## Игры (🎮)
- 🧨 Мины: 1/3/5/10 мин, 5×5, честные кэфы (комиссия 2%). **Состояние в БД** — переживает перезапуск.
- 🚀 Crash: растущий множитель, заберите до взрыва. Краш-поинт: P(x≥m)=0.97/m (эдж 3%).
- 🪙 Монетка: орёл/решка x1.95, после выигрыша можно удваивать подряд.
- 🎲 Кости: больше 3 / меньше 4, x1.9, анимация кубика Telegram.
- 🎰 Слоты: анимация 🎰 (send_dice). 💎💎💎 x20, 777 x40, три любых x8, две подряд x2.
- 🃏 Блэкджек: против дилера, блэкджек x2.5.
- 🎡 Колесо фортуны: EV 95.5%.

## Ставки
- Одиночные: П1 / Х / П2 / обе забьют.
- 🧾 Экспрессы: до 5 исходов, кэфы перемножаются. Авторассчёт при завершении матчей.
- 🔔 Уведомления: о выигрыше/проигрыше, о начале матча.
- ⏰ Автозакрытие приёма по start_time (фоновая задача).

## Удержание
- 🎁 Бонус каждый день, серия увеличивает бонус (потолок 500). Опционально проверка подписки (CHANNEL_ID).
- 🏅 10 достижений с наградами монетами.
- 🏆 Топ дня (большие кэфы), топы недели/месяца; админ выдаёт призы кнопками.
- 👥 Рефералка: +50 пригласившему, +25 другу.
- 🎁 Переводы между игроками (комиссия 10%, мин. 50).

## Админ-панель (/admin)
Монеты, бан, поиск игрока с историей, промокоды, матчи (CRUD, завершение с
автовыплатой, изменение результата с пересчётом), загрузка матчей из API
(The Odds API через ODDS_API_KEY или файл matches.json), рассылка, статистика
(прибыль «казино»), призы недели/месяца, бэкап БД (кнопка + автобэкап раз в сутки).

## Надёжность
- Антиспам: до 15 апдейтов/10 сек с пользователя.
- Активные игры в SQLite — после перезапуска мины/блэкджек продолжаются, crash-ставки возвращаются.
- Токен через переменные окружения.

⚠️ Только виртуальные монеты. Ставки на реальные деньги без лицензии незаконны.
